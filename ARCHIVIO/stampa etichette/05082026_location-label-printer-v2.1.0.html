🖨️ Metodo 1 — Zebra Designer 3 (consigliato)

                
    
                  
  1. Premi Genera ZPL e poi Scarica .zpl
    2. 
                  
  2. Apri Zebra Designer 3
    3. 
                  
  3. Menu File → Open → seleziona il file .zpl
    4. 
                  
  4. Zebra Designer mostra l'anteprima delle etichette
    5. 
                  
  5. Verifica layout → File → Print sulla Zebra
    6. 
                

                
⚠ Zebra Designer 3 Free supporta apertura ZPL. La versione Pro aggiunge modifica.

              


              

                
🌐 Metodo 2 — Zebra Browser Print

                
    
                  
  1. Installa Zebra Browser Print sul PC con la stampante
    2. 
                  
  2. Avvia il servizio Browser Print
    3. 
                  
  3. Premi Genera ZPL → Copia ZPL
    4. 
                  
  4. Apri l'interfaccia web di Browser Print
    5. 
                  
  5. Incolla il codice e invia direttamente alla Zebra
    6. 
                

                
⚠ Zebra Browser Print è gratuito, scaricabile da zebra.com/support

              


              

                
🖥️ Metodo 3 — Rete diretta (porta 9100)

                
    
                  
  1. Premi Genera ZPL → Scarica .zpl
    2. 
                  
  2. Apri il Prompt dei comandi come amministratore
    3. 
                  
  3. Esegui il comando:
    
                    copy etichette.zpl \\IP_STAMPANTE\raw
    
                    oppure con PowerShell:
    
                    Get-Content etichette.zpl | Out-Printer "\\IP\ZebraRaw"
                  
    4. 
                

                
⚠ La Zebra deve essere condivisa in rete con coda RAW abilitata.

              


              

                
📡 Metodo 4 — USB diretta (Windows)

                
    
                  
  1. Collega la Zebra via USB al PC
    2. 
                  
  2. Nelle proprietà stampante Windows, crea una porta USB virtuale RAW
    3. 
                  
  3. Premi Genera ZPL → Scarica .zpl
    4. 
                  
  4. Da Prompt amministratore:
    
                    copy etichette.zpl COM3:
    
                    (sostituisci COM3 con la porta COM della Zebra)
                  
    5. 
                

              


              

                
📐 Impostazioni Zebra consigliate per 100×80mm

                
    
                  
  • Verifica che la Zebra sia configurata per etichette 100×80mm (imposta dal pannello o via ZPL ^PW e ^LL)
    • 
                  
  • Modalità di stampa: Direct Thermal (se usi carta termica diretta) o Thermal Transfer (se usi ribbon)
    • 
                  
  • Il codice ZPL generato include già ^PW (larghezza) e ^LL (altezza label) per 203 DPI o 300 DPI in base alla selezione
    • 
                  
  • Se la stampa risulta tagliata o spostata, verifica che il sensore gap della Zebra sia calibrato per l'etichetta utilizzata
    •
